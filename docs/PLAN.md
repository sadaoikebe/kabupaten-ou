県境王のプログラム、文章、色、画像、効果音、国土地理院タイルはコピーしない。30秒で陸の県境をなぞる、という遊びの手順は合わせる。採点の計算、称号、画面の文はカブパテン王で書く。

## 本体で確認した遊び

2026-10-21 に公開ページを開いて確認した。

- 地方を選ぶ。選んだ地方の中から 1 問が出る。今の県境王は地方までで、県単位では選べない。
- スタートで 30 秒。下見時間はない。残りは 0.1 秒単位。5 秒を切ると急かす。
- お題の県境を、色別標高図の上になぞる。海岸線と離島は描かなくてよい。海上の線は採点しない。
- 陸や海岸からドラッグすると線になる。沖でドラッグすると地図が動く。
- 道具は、描く、移動、消しゴム、全消去、1 本戻す。ホイール、＋/−、全体表示で拡大する。2 本指でも拡大・移動できる。
- 時間内に提出するか、0 秒で採点する。
- 採点は、描いた線と本当の県境線の近さ。許容の基準は 20 km。満点は 10 万点。
- ランクは一致率で決まる。98% 以上が S、90% 以上が A、60% 以上が B、55% 以上が C、35% 以上が D、それ未満が E。
- 結果では点数、ランク、自分の線、正解の線を出す。結果の文をコピーできる。
- 答え合わせのあと、その県が画面に収まる。プレイ中は県名ラベルを地図に出さない。
- 1 問ずつ。同じ地方では、一巡するまで同じ県を出さない。

足していたが、本体にないのでやめるもの: 下見 8 秒、易しい／難しいの別モード、面積の IoU を得点にすること、再現率の表示、市を混ぜる設定、勝手な称号（通、観光客、迷子）。

## カブパテン王での対応

- 画面で選べるのはジャワ島、スマトラ島、カリマンタン、スラウェシ島、ヌサ。出題はその島の県をまとめたもの。ジャワ島はバンテン、ジャカルタ、西ジャワ、中央ジャワ、ジョグジャカルタ、東ジャワ。スマトラ島はランプンからアチェまでと、バンカ・ブリトゥン、リアウ諸島。州ごとの地図は残してあり、`src/groups.ts` の `USE_ISLAND_SELECT` を false にすると州ごとの選択に戻る。マルクと北マルクはデータだけ残し、画面には出さない。ジョグジャカルタの州データは中央ジャワに混ぜない。
- 出題は県（kabupaten）だけ。市（kota）は出題しない。県の穴や隣との境界には使う。
- 県の名前は `Bogor県` のように、データの県名に「県」を付ける。称号はカブパテン王の文にする。S は「Bogor県のカブパテン王」、E は「振り出し」。
- なぞる線は、隣の県・市と接している陸の境界。海に面した線と、離島の輪郭は正解に入れない。陸の境界が無い県だけ、本体の離島県と同じく主島の海岸線をなぞる。西・東・北カリマンタンのマレーシアとの陸境と、東ヌサトゥンガラの東ティモールとの陸境は、隣国の県界を使わず、境界の外側が標高で陸のところだけ正解に入れる。
- 地図は選んだ島全体の色別標高図。中身は州ごとの図を並べたもの。ラベル、道路、境界線はプレイ中に出さない。拡大はプレイ中にできる。30 秒は止まらない。
- 地形は Terrain Tiles（`elevation-tiles-prod` の skadi）の SRTM。パブリックドメイン。USGS のクレジットを画面に書く。NASADEM ではない。正答の境界は geoBoundaries の IDN ADM2、コミット `9469f09`、表現年 2020。配布は CC BY 4.0、元データ（BPS / WFP / OCHA ROAP）は CC BY 3.0 IGO。画面に両方のリンクと、形を間引いた旨を書く。

## データ

- 生ファイルは `data/raw/`。Git には入れない。
- ゲームが読むのは `data/dist/` の地方ごとの json と webp。西ジャワは `jawabarat`、中央ジャワは `jawatengah`、東ジャワは `jawatimur`、ランプンは `lampung`、南スマトラは `sumsel`、バンカ・ブリトゥンは `babel`、ベンクルは `bengkulu`、西カリマンタンは `kalbar`、中部カリマンタンは `kalteng`、ジャンビは `jambi`、リアウ諸島は `kepri`、西スマトラは `sumbar`、リアウは `riau`、バリは `bali`、南カリマンタンは `kalsel`、西ヌサトゥンガラは `ntb`、北スマトラは `sumut`、東カリマンタンは `kaltim`、南スラウェシは `sulsel`、北カリマンタンは `kaltara`、西スラウェシは `sulbar`、アチェは `aceh`、東ヌサトゥンガラは `ntt`、中部スラウェシは `sulteng`、南東スラウェシは `sultra`、ゴロンタロは `gorontalo`、北スラウェシは `sulut`、北マルクは `malut`、マルクは `maluku`、バンテンは `banten`、ジャカルタは `jakarta`、ジョグジャカルタは `yogyakarta`。
